# 🏍b️ Fitness App

A **Flutter-based fitness application** integrated with **Firebase** to help users track workouts, set goals, and maintain a healthy lifestyle. The app provides personalized fitness plans, real-time progress tracking, and an intuitive UI for a seamless user experience.

## 🚀 Features

- 📋 **Workout Tracking** – Log and track daily exercises with real-time updates.
- 🎯 **Goal Setting** – Set fitness goals and monitor progress over time.
- 📅 **Workout Schedules** – Plan and schedule workouts with reminders.
- 🔐 **Firebase Authentication** – Secure login/signup with Google, email, or phone.
- ☁ **Cloud Storage** – Save user data and progress using **Firebase Firestore**.
- 📸 **Media Support** – Upload workout images and progress pictures.
- 🎵 **Music Integration** – Play motivational music during workouts.

## 🛠️ Tech Stack

- **Flutter** – UI framework for building cross-platform mobile applications.
- **Firebase** – Backend for authentication, database, and cloud storage.
- **Provider/Cubit** – State management for responsive UI.
- **Shared Preferences** – Store user settings and preferences locally.
- **Dart** – Programming language for Flutter development.

## 📦 Installation

1. **Clone the repository:**  
   ```sh
   git clone https://github.com/sayedmaltan/Fitness-App.git
   cd fitness-app
   ```  

2. **Install dependencies:**  
   ```sh
   flutter pub get
   ```  

3. **Run the app:**  
   ```sh
   flutter run
   ```  

## 🔥 Firebase Setup

To use Firebase services, follow these steps:  

1. Create a Firebase project on the [Firebase Console](https://console.firebase.google.com/).  
2. Enable Authentication (Google, Email/Password).  
3. Set up Firestore Database & Storage.  
4. Download the `google-services.json` (Android) and `GoogleService-Info.plist` (iOS) and place them in the appropriate directories.
